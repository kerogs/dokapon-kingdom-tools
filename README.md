# Dokapon Kingdom Tools (DKT)
A collection of tools, calculator and guides for Dokapon Kingdom and it's different versions

## Styling

This project uses **SCSS (Sass)** for its stylesheets.

You don't need advanced Sass knowledge to contribute! Regular CSS syntax is fully supported in `.scss` files.

### Development

1. Install dependencies with `npm install`.
2. Run `npm run watch:css` to automatically compile styles while developing.
3. Edit the source files in `src/scss/`.

**Important:** Files in `website/assets/css/` are generated automatically. Please don't edit them directly.

The compiled CSS is generated during the GitHub Pages deployment.
